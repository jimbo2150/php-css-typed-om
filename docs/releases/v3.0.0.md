# php-css-typed-om v3.0.0 Release Notes

`v3.0.0` is a major standards-compliance, capability, security, and performance release targeting **PHP 8.4+** with zero runtime dependencies.

---

## Highlights

- **CSS Values & Units Level 4:** Full calculation-tree support for Level 4 math functions (`CSSMathFunction`: `round()`, `mod()`, `rem()`, `sin()`, `cos()`, `tan()`, `asin()`, `acos()`, `atan()`, `atan2()`, `pow()`, `sqrt()`, `hypot()`, `log()`, `exp()`, `abs()`, `sign()`), math constants (`CSSMathConstant`: `e`, `pi`, `infinity`, `-infinity`, `NaN`), IEEE-754 degenerate clamping, and iterative §10.10 simplification (`simplify()`, `clampToRange()`).
- **CSS Color Level 4 & Level 5:** Complete functional color parsing and conversions (`srgb`, `srgb-linear`, `display-p3`, `a98-rgb`, `prophoto-rgb`, `rec2020`, `xyz`, `xyz-d50`, `xyz-d65`, `lab`, `lch`, `oklab`, `oklch`, `hsl`, `hwb`), `color-mix()`, Relative Color Syntax (`from <color>`), context-resolved `light-dark()`, `none` missing-component propagation, and OKLCH binary-search gamut mapping (`inGamut()`, `toGamut()`).
- **Geometry Interfaces Level 1:** Completed the geometry model with `DOMPointReadOnly`, `DOMPoint`, `DOMRectReadOnly`, `DOMRect`, and `DOMQuad` alongside 2D/3D-compliant `DOMMatrixReadOnly` and `DOMMatrix`.
- **CSS Syntax Level 3 & W3C Property Grammars:** Added `CSSInputPreprocessor`, `CSSTokenizer`, `CSSSelectorList`, `CSSMediaQueryParser`, full W3C Value Definition Syntax property grammar validation (`CSSValueValidator`, `CSSPropertyGrammarRegistry`), complete §6.7 shorthand expansion/serialization, `@color-profile` (`CSSColorProfileRule`), `@custom-media` (`CSSCustomMediaRule`), opt-in `$browserErrorRecovery`, and opt-in `$trackSpans` (`CSSSourceSpan`).
- **Major Performance Improvements:** Rewrote core hot paths with zero-copy slicing, fast ASCII paths, bitmask flags, and consolidated codecs — speeding up stylesheet rendering by **53%–55%**, color parsing/conversion by **49%**, transform/matrix operations by **44%**, scanner validation by **43%**, and CSSOM mutation by **41%** over baseline benchmarks.

## Breaking Changes & Upgrade Notes

1. **Removed non-standard trait hierarchy & legacy property list:**
   - Removed `src/TypedOM/Traits/*` (`LengthTrait`, `MultiValueArrayTrait`, `MultiValueTrait`, `SimpleValueTrait`, `TypeableUnitTrait`) and their corresponding docs. Typed OM classes implement their methods directly without exposing non-W3C trait types.
   - Removed `src/CSSOM/CSSStandardProperties.php`; standard property lookups and Value Definition Syntax grammars now live in `CSSPropertyGrammarRegistry` (`CSSValueValidator` / `@internal` registry).
2. **Stricter W3C Grammar & Validation Enforcement:**
   - Standard declarations validated through `CSSStyleDeclaration` / `StylePropertyMap` now check W3C Value Definition Syntax grammars (including case-insensitive keyword matching and `@property` syntax validation) rather than structural tokens alone.
   - `CSSColorValue::parse()` raises `CSSDeferredColorException` when directly evaluating deferred color expressions (such as `var()` references or unconfigured `currentcolor` / `light-dark()`), while `CSSStyleValue::parse()` retains them as `CSSUnparsedValue`.
   - `CSSUnitValue::$value` enforces strict finite IEEE-754 `double` semantics; degenerate math results (`infinity`, `-infinity`, `NaN`) are represented via `CSSMathConstant` / math calculation trees.
   - CSS `<number-token>` validation rejects non-standard forms such as trailing decimal dots (`10.`).
3. **`@internal` API Surface Clarification:**
   - Internal helper methods and constants (`CSSUnitEnum` conversion/lookup helpers, `CSSMathFunctionEnum` metadata helpers, `CSSSyntaxScanner` byte-mask constants, and internal `*Internal()` helpers) are tagged `@internal`. Public API documentation is cataloged in [docs/interfaces.md](../interfaces.md).

## Security & Robustness

- **Iterative Traversals Everywhere:** Parsers, serializers, cloners, type evaluators, and `CSSMathSimplifier` use explicit iterative stacks with depth and node-allocation caps (`MAX_MATH_NODES`, `MAX_MATH_TREE_DEPTH`).
- **Resource Limits:** Enforced consistently across parsing, shorthand expansion/serialization, and math simplification (`CSSParserOptions`: `maxBytes`, `maxDepth`, `maxRules`, `maxMathDepth`, `maxErrors`, `maxDeclarations`).
- **Injection & Control-Byte Defenses:** Atomic upfront control-byte rejection (`\x00–\x08`, `\x0B`, `\x0E–\x1F`, `\x7F`), balanced delimiter/quote/comment/unquoted-`url()` enforcement, top-level `;`/`{`/`}` structural injection guards across selectors, preludes, `@import` media clauses, and `CSSImageValue`, plus HTML `<style>` tag escaping (`CSSRenderOptions::$escapeHtmlStyleTag`).
